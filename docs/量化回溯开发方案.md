# 📊 量化回溯（回测）开发方案

> 适用策略：**KDJ双金叉**（首个落地策略，引擎按通用接口设计，后续可接入其它选股策略）
> 文档类型：开发方案
> 目标市场：沪深A股（日线级别）
> 方案版本：v1.0
> 文档状态：方案设计，未开发
> 关联文档：[KDJ双金叉投资与开发方案](KDJ双金叉投资与开发方案.md)

## 一、目标与边界

### 1.1 目标

1. 用历史日线数据**完整复现 KDJ双金叉 的选股与交易流程**，输出可复现的回测报告。
2. 验证「5~10 日二次金叉 + 死叉确认 + 信号新鲜度 + 均线站上」组合的**胜率、盈亏比、最大回撤**。
3. 支持**参数网格与样本外验证**，为 v1.3 的均线三选项、市值上限扩展提供数据依据。
4. 回测结果可导出（CSV / HTML），并与实盘扫描信号做一致性抽查。

### 1.2 非目标（本期不做）

- 不做实盘自动下单、不接 QMT/券商交易接口。
- 不做分钟级/高频回测，仅日线级别。
- 不做机器学习参数寻优，仅规则化网格 + 样本外验证。
- 不处理融资融券、分红再投资、ETF、可转债等品种。

## 二、现状与复用清单

| 现有模块 / 函数 | 回测用途 |
|---|---|
| `kdj_double_gold_selector.calculate_indicators` | 复用 KDJ(9,3,3) + MA5/MA10/MA20，保证与实盘指标口径一致 |
| `kdj_double_gold_selector.detect_double_gold_cross` | 二次金叉信号检测（需改造为「截至某一交易日」的切片调用） |
| `kdj_double_gold_selector.score_signal` | 信号强度评分，用于多信号排序与仓位分配 |
| `kdj_double_gold_selector.get_kline_history` | 前复权日线获取与降级链（麦蕊 → 东财/akshare → 新浪） |
| `mairui_client` / `data_source_manager` | 历史日线数据源，回测默认使用前复权 |
| `kdj_double_gold_selector._filter_pool` | 候选池市值/板块/ST 过滤规则复用（回测需按历史时点重建） |
| `notification_service`（可选） | 回测完成后的钉钉/飞书结果推送 |

> **关键原则**：回测与实盘必须共用同一套指标与信号函数，禁止复制粘贴后各自演化，避免"回测一套、实盘一套"。

## 四、数据层设计

### 4.1 数据范围与口径

| 项 | 约定 |
|---|---|
| 标的范围 | 沪深A股主板（默认排除科创板/北交所，创业板可配置） |
| 行情周期 | 日线（开/高/低/收/成交量/成交额） |
| 复权方式 | **前复权（qfq）**，除权除息日必须正确复权 |
| 回测区间 | 默认近 2 年；参数寻优建议 2019-01-01 起 |
| 预热数据 | 每段回测起点前多取 **60 个交易日**（KDJ 9 日 + 间隔窗口 + MA20 预热） |
| 交易日历 | 以上交所/深交所实际交易日为准（缓存 `trade_calendar.csv`） |

### 4.2 数据获取与缓存

1. 数据源优先级沿用现有链路：**麦蕊 MyData → 东财/akshare → 新浪日线**。
2. 回测只接受能提供**前复权**的数据源；新浪源为不复权，命中时在报告中标注「数据口径降级」并给出告警。
3. 首次全量下载后落本地缓存：

```
data/backtest_cache/
  daily/{code}.parquet        # 单只股票日线（升序，含复权标记）
  calendar/trade_calendar.csv # 交易日历
  universe/universe_{date}.csv# 各月末/各交易日可交易股票池快照
```

4. 增量更新：按缓存最后日期补齐，避免重复拉取。
5. 批量拉取限流：逐只 `sleep`，可选并发；失败股票记录清单并在报告中披露覆盖率。

### 4.3 历史状态还原（避免幸存者偏差）

- **股票池**：按历史时点重建，退市/暂停上市股票保留至其最后交易日，不得用"今天仍存续"的股票池回溯。
- **ST 状态**：使用历史 ST 标记（若数据源无历史标记，报告需声明近似处理）。
- **停牌**：停牌日不生成信号、不可成交，持仓按停牌前收盘价估值并标记。
- **涨跌停**：涨停不可买入、跌停不可卖出，按当日 `open/high/low/close` 判定。
- **上市不足 60 日**：不进入候选池（指标预热不足）。

## 五、信号回放设计

### 5.1 杜绝未来函数

- 所有指标与信号只能使用 **≤ T 日**的数据；T 日收盘后生成信号，**T+1 开盘**执行。
- `detect_double_gold_cross` 以 `df.iloc[:T+1]` 切片调用；禁止先算全量指标再回看。
- 如后续引入财务/事件数据，必须按**公告日**而非报告期入库。
- 提供自动检查：对同一股票随机抽取 20 个交易日，验证"切片调用"与"全量结果在 T 日"完全一致。

### 5.2 策略适配器输出结构

```python
{
    'signal_date': '2026-10-30',      # T 日（收盘后）
    'stock_code': '600XXX',
    'stock_name': 'XXX',
    'score': 70,                       # 复用 score_signal
    'gap': 7,                          # 两次金叉间隔
    'cross_k': 45.2,                   # 第二次金叉 K 值
    'stop_loss_ref': 12.30,            # 第二次金叉日最低价
    'market_cap': 88.0,                # 亿元（历史时点市值）
    'ma_flags': ('MA5', 'MA10'),       # v1.3 均线选项
}
```

### 5.3 信号漏斗统计

每次回测输出筛选漏斗，定位"为什么没信号"：

```
全市场 → 候选池(市值/板块/ST) → 有足够K线 → 金叉≥2次
      → 间隔5~10日 → 存在死叉 → 新鲜度<3日 → 金叉K值≤上限 → 均线站上 → 最终信号
```

各环节留存数量与占比写入报告，便于与实盘扫描日志对照。

## 六、交易撮合与组合规则

### 6.1 买入

| 规则 | 说明 |
|---|---|
| 成交时点 | 信号次日（T+1）**开盘价**成交 |
| 放弃条件 | T+1 开盘涨幅 > 5% 放弃（可配置） |
| 无法成交 | 一字涨停、停牌、无报价 → 放弃并记录原因 |
| 滑点 | 默认 0.1%（可配 0~0.3%），买入价 = 开盘价 × (1 + 滑点) |
| 排序 | 按信号评分降序，评分相同按市值升序 |
| 仓位 | 总资金默认 10 万；单股 ≤ 30%；最多持有 4 只；单日最多新买 2 只 |
| 资金不足 | 跳过该信号，继续尝试下一只（不拆单） |

### 6.2 卖出（T 日收盘判定，T+1 开盘执行）

| 规则 | 触发条件 | 执行 |
|---|---|---|
| 技术止损 | 收盘价 < 第二次金叉日最低价，或浮亏 ≥ 8% | 次日开盘清仓 |
| 超买止盈 | J > 100 且 KDJ 死叉；或浮盈 ≥ 15% 减半、≥ 20% 清仓 | 次日开盘执行 |
| 时间止损 | 持股满 10 个交易日且涨幅 < 3% | 次日开盘清仓 |
| 趋势破坏 | 收盘价跌破 MA20 → 减半；连续 3 日跌破 → 清仓 | 次日开盘执行 |
| 跌停/停牌 | 无法卖出 | 顺延至下一可成交日，记录滑点损失 |

> 同一标的的多条卖出规则按"先止损、后止盈/时间/趋势"优先级判定，避免重复下单。

### 6.3 交易费用

| 费用 | 默认参数 |
|---|---|
| 佣金 | 万 2.5，双边，最低 5 元 |
| 印花税 | 卖出 0.05% |
| 过户费 | 成交金额 0.001%（双边） |
| 滑点 | 买/卖各 0.1% |

费用参数全部可配置，报告中需列明，禁止"零成本回测"。

### 6.4 估值与净值

- 每日收盘后按收盘价估值（停牌按最后收盘价）。
- 净值曲线 = (现金 + 持仓市值) / 初始资金，按交易日序列输出。
- 分红送转：以前复权价格序列自动隐含处理，不单独发放现金红利。

## 七、绩效指标与报告

### 7.1 核心指标

| 类别 | 指标 |
|---|---|
| 收益 | 累计收益、年化收益、超额收益（相对沪深300/中证500） |
| 风险 | 最大回撤、回撤持续天数、年化波动率 |
| 风险调整 | 夏普比率、卡玛比率、索提诺比率 |
| 交易 | 总笔数、胜率、盈亏比、平均持仓天数、最大单笔盈亏、换手率 |
| 稳定性 | 分年度收益、分市值区间收益、分金叉间隔(5-7/8-10)收益 |

### 7.2 报告输出

```
reports/backtest/{run_id}/
  summary.json        # 参数快照 + 核心指标 + 数据覆盖率
  trades.csv          # 每笔交易明细（信号日、买卖日、价格、费用、盈亏、退出原因）
  equity_curve.csv    # 每日净值、基准净值、回撤
  report.html         # 汇总页（Plotly 图表 + 表格）
  funnel.csv          # 信号漏斗统计
```

图表至少包含：权益曲线 vs 基准、回撤曲线、月度收益热力图、交易盈亏分布、参数网格热力图。

### 7.3 基准

- 默认基准：沪深300（大盘）与中证500（中盘）双基准对照。
- 可选基准：回测区间内**等权全市场**收益，用于判断策略是否有真实选股 alpha。

## 八、参数网格与稳健性验证

### 8.1 网格维度（对应 v1.3 方案）

| 维度 | 取值 |
|---|---|
| 金叉间隔 | 5~7 / 8~10 / 5~10 |
| 市值区间（亿） | 50~250 / 50~1000 / 50~10000 |
| 金叉 K 值上限 | 50 / 65 / 80 |
| 均线站上选项 | MA5 / MA5+MA10 / MA5+MA10+MA20 |
| 信号新鲜度 | 1 / 2 / 3 日 |

> 网格组合数 = 3×3×3×3×3 = 243 组；建议先做单因子敏感性分析，再对高潜力区间做二维/三维组合，避免全量暴力搜索。

### 8.2 样本切分

- 训练期：前 70% 时间；验证期：后 30%。
- 采用 **walk-forward**（滚动训练 + 后续验证），避免用全样本最优参数直接报告。
- 报告必须同时给出**样本内与样本外**结果；样本外显著劣化则判定参数不稳定。

### 8.3 防止过拟合

- 单参数组合交易样本 < 30 笔时，结果标注"样本不足，不具统计意义"。
- 参数邻域稳定性：最优参数相邻取值的收益不应断崖式下降。
- 不以单一最高收益参数作为结论，优先选择"收益-回撤-样本量"均衡区间。

## 十三、风险与注意事项

1. **幸存者偏差**：必须保留退市股与历史成分，否则胜率会被系统性高估。
2. **未来函数**：任何"用当日收盘后才知道的信息在当日成交"都是未来函数；本方案统一采用 T 日收盘信号、T+1 开盘成交。
3. **前复权口径**：不同数据源复权因子差异会导致指标偏差，报告中需注明数据源与复权方式；新浪源不复权仅作兜底。
4. **涨跌停/停牌**：不回测这些约束会显著虚增收益，必须按可成交性过滤。
5. **流动性**：策略偏向中盘股，需校验单笔成交额占当日成交额比例（建议 < 5%），避免纸面成交。
6. **过拟合**：参数网格结果不得直接用于实盘，必须经过样本外验证与实盘小资金验证。
7. **交易规则差异**：回测撮合与真实盘口存在差异（集合竞价、大单冲击），结论应保守解读。
8. 本方案仅供学习研究，不构成投资建议。

## 十四、二期扩展（可选）

- **多策略对比**：同一引擎接入低价擒牛、小市值、净利增长等策略，统一基准对比。
- **组合级回测**：多策略信号合并后的资金分配与相关性分析。
- **每日增量回测**：定时任务每日收盘后滚动更新近 N 日信号表现。
- **实盘对照**：将回测信号与实时监测/模拟持仓对照，追踪信号衰减。
